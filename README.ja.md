# LLM Vegas

*[English](README.md) | 日本語*

Claude が output トークンを 10,000 使うたびに、勝手に 1 回転するスロットです。


## 動作環境

- macOS
- Node.js 20 以上
- Claude Code `~/.claude/projects` に transcript を書き出していること

## インストール

```bash
brew install todokr/tap/llm-vegas
llm-vegas
```

初回起動時だけ Electron ランタイムを `~/Library/Application Support/LLM Vegas/runtime` に展開するため数秒かかります。2 回目以降は待ちません。

ソースから動かす場合は次のとおりです。

```bash
npm install
npm start
```

画面右上に小さな筐体が現れ、他のどのウィンドウよりも手前に居続けます。マーキー部分をドラッグすれば移動できます。`🔊` で全体ミュート、`🎵` で BGM の切り替え、`✕` で終了です。

**どこにも何も送信しません。** ローカルのファイルを読むだけで、ネットワークとは一切話しません。

## 仕組み

Claude Code は応答のたびに `~/.claude/projects` 以下の JSONL へ 1 行ずつ追記します。LLM Vegas はこのファイル群を 1 秒ごとにポーリングし、**起動後に追記された `output_tokens` だけ**を数えます。

10,000 トークンで 1 回転です。溜まった回転はキューに積まれ、順に自動で消化されます。

サブエージェントやバックグラウンドのワークフローも当然カウントされます。待機中の回転が 5 つ以上たまると `TURBO` に入り、2.4 倍速で消化します。

## 確率

**当落はリールが動く前に決まります。** 実機と同じです。リールのほうが後から結果に合わせて組み直され、その位置で止まります。

| 結果 | 通常 | LLM RUSH 中 | 払い出し |
| --- | --- | --- | --- |
| ハズレ | 79.8% | 44% | 0 |
| チェリー | 14% | 30% | 10 |
| ゾロ目 | 5% | 22% | 200 |
| 777 | 1.2% | 4% | 7777 |

だいたい 5 回に 1 回は何かが当たります。1 日 50 回転として、777 は 1〜2 日に 1 回の頻度です。

## 演出

**先読み予告。** 結果が先に決まっているので、それを知った上で正直に煽れます。信頼度 0〜3 を結果ごとの重み付きテーブルから引き、ハズレならたいてい 0、777 ならほぼ 3 が出ます。この信頼度が筐体の色（青 → 緑 → 赤）、カットイン（`CHANCE` / `HOT!!` / `SUPER HOT!!!`）、逆回転してから回り出すギミック、音声を決めます。信頼度 2 以上はロングリーチに発展し、第 3 リールが 1 コマずつ這って進みます。

**LLM RUSH。** ゾロ目で 10 回転、777 で 30 回転の RUSH に突入します。継続中は上の表の右列に確率テーブルが差し替わり、筐体が色相を回しながら脈打ち、BGM のテンポも上がります。

**音声。** OS の音声合成が `BIG WIN` や `JACKPOT` を叫びます。777 のあとには `Seven! Seven! Seven!` と `Congratulations` が追い討ちで入ります。

**デスクトップ全体のネオン枠。** 大当たりの間、透明なクリックスルーのウィンドウがディスプレイの四辺を虹色に走ります。フォーカスを奪わずクリックも通すので、その下で作業は続けられます。

**777。** 暗転し、カットインが入り、筐体が手前に迫り、そしてウィンドウが数秒間だけ画面全体を占拠します。光の柱、コインの奔流、7777 まで回るカウンタ。これは本当に作業を止めます。そういう演出です。

**散財メーター。** 使った output トークンをドル換算して常時表示します。下の警告も読んでください。

## 設定

調整できるものは `src/renderer/config.ts` に集めてあります。

| 定数 | 意味 |
| --- | --- |
| `TOKENS_PER_SPIN` | 1 回転に必要な output トークン |
| `ODDS` / `ODDS_RUSH` | 確率テーブル（通常・RUSH 中） |
| `PAYOUT` | 結果ごとの払い出し |
| `RUSH_SPINS` | 当たり後の RUSH 継続回転数 |
| `TENPAI_RATE` | ハズレのうち煽りを入れる割合 |
| `RUSH_THRESHOLD` | TURBO に入る待機回転数 |
| `USD_PER_MTOK_OUTPUT` | 散財メーターの換算レート |

> **散財メーターはジョークであって請求書ではありません。** output トークン数に、ハードコードされたレート（既定は 100 万トークンあたり $75）を掛けているだけです。この値はどこからも取得しておらず、あなたのプランにもモデルにも実際の利用額にも紐づいていません。実際の支出として受け取らないでください。

## 開発

```bash
npm run build         # main / preload / renderer をコンパイル
npm run watch-test    # watcher が起動後の追記だけを数えることを検証
```

デバッグ用の入口があります。

```bash
LLM_DEBUG=1 npm start         # 起動直後に 30,000 トークンを注入（3 回転）
LLM_DEBUG=jackpot npm start   # 起動直後に 777 を強制
LLM_DEBUG=audit npm start     # 3,000 回ぶんを試行して JSON で出力
```

`audit` は抽選とリール配置を何千回も再生し、辻褄の合わない結果が出ていないかを報告します。

```
[audit] {"n":3000,"centerMismatch":0,"fakeRows":0,"teasers":[1846,739,294,121]}
```

アプリ上では、筐体をダブルクリックで 1 回転、Shift + ダブルクリックで 777 を強制できます。

## 構成

```
src/main/index.ts      ウィンドウ生成、777 の全画面膨張、ネオン枠、IPC
src/main/watcher.ts    transcript のポーリングと output トークンの集計
src/main/store.ts      累計統計（userData/stats.json）
src/renderer/          筐体、リール、パーティクル、合成音、音声
```
