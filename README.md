# LLM Vegas

Claude が output トークンを吐くほど、勝手に回るスロット。自分用のジョークおもちゃ。

UI はすべて英語。コードのコメントとこのドキュメントは日本語のまま。

## 起動

```bash
npm install
npm start        # ビルドして起動
```

画面右上に frameless の小窓が最前面で常駐する。マーキー部分をドラッグで移動、`✕` で終了、`🔊` で全体ミュート、`🎵` で BGM だけ切り替え。

## 音

全部その場で合成していて、音声ファイルは 1 つも持たない。

- **BGM** — Am / F / C / G の 4 小節ループ。ベース・16分アルペジオ・キック・スネア・ハイハットを WebAudio のスケジューラで 16 分刻みに並べている。起動と同時に鳴る
- **効果音** — 回転中のモーター音（速度で音程が動く）、リール停止のガコン、テンパイの心音、当たりのファンファーレ、コインの落ちる音
- 当たり演出の間は BGM が自動で引っ込む（ダッキング）
- `BONUS RUSH` 中は BGM のテンポが 148 → 190 に上がり、アルペジオにオクターブ上が重なる

## 仕組み

- `~/.claude/projects/**/*.jsonl` を 1 秒ごとにポーリングし、**追記された分の `output_tokens` だけ**を数える
- **10,000 output トークンごとに 1 回転**。回転は全自動
- 起動時点の各ファイル末尾を記憶するので、**アプリを閉じている間の消費は数えない**
- 溜まった回転が 5 以上になると `TURBO` に入り、高速で消化する（ワークフローやサブエージェントを回すと発生しやすい）
- トークンが届くたび、画面の外からコインが投入口に吸い込まれる

## 演出

**先読み予告** — 当落は回転前に決まっているので、それを知った上で煽れる。信頼度 0〜3 を重み付きで抽選し、筐体の色（青 → 緑 → 赤）、カットイン（`CHANCE` / `HOT!!` / `SUPER HOT!!!`）、逆回転してから回り出すギミック、音声を出し分ける。信頼度 2 以上ではロングリーチに入り、第3リールが 1 コマずつ這う。

**LLM RUSH** — 大当たりの後に突入する。ゾロ目で 10 回転、777 で 30 回転。継続中は確率テーブルが別物になり（777 が 1.2% → 4%、ゾロ目が 5% → 22%）、筐体が虹色に脈打ち、BGM のテンポも上がる。当たった後が本番。

**音声** — OS の音声合成に叫ばせる。`BIG WIN` / `JACKPOT` / `Super hot`、777 のときは追い討ちで日本語の棒読みも入る。ミュートボタンで声も止まる。

**デスクトップ全体のネオン枠** — 大当たりと 777 の間、画面の四辺を虹色のフレームが走る。クリックスルーの透明ウィンドウなので作業は止まらない。

**777 のシネマ演出** — 暗転 → `777` のカットイン → 筐体が迫り上がる → 爆発 → 画面全体を占拠。

**散財メーター** — 累計 output トークンをドル換算して常時晒す。レートは `config.ts` の `USD_PER_MTOK_OUTPUT`（既定 $75 / 100万トークン、ジョーク用のざっくり値）。

## 当たり

実機と同じで**当落が先に抽選され、リールはその結果に合わせて止まる**。だから「揃いかけて止まる」煽りが確実に作れる。

**有効ラインは中央の 1 本だけ**（赤いラインと左右の ▶◀ が目印）。上下の段は暗く落としてある。さらに、上下の段がたまたま 3 つ揃って「揃ったのに何も出ない」と見えてしまう並びは、帯を組み直して排除している（`LLM_DEBUG=audit` で 3000 回検証できる）。

| 役 | 確率 | 払い出し | 演出 |
| --- | --- | --- | --- |
| ハズレ | 79.8% | 0 | うち 30% はテンパイ煽り付き |
| チェリー | 14% | 10 | フラッシュ・紙吹雪・小ファンファーレ |
| ゾロ目 | 5% | 200 | 画面シェイク・コイン投下・ファンファーレ |
| 777 | 1.2% | 7777 | **ウィンドウが画面全体に膨張**して数秒間すべてを奪う |

体感で約 5 回に 1 回当たる。1 日 50 回転想定なので大当たりは 1〜2 日に 1 回。

## 設定

`src/renderer/config.ts` に全部ある。

- `TOKENS_PER_SPIN` — 1 回転あたりのトークン
- `ODDS` / `PAYOUT` — 確率と払い出し
- `TENPAI_RATE` — ハズレのうち煽る割合
- `RUSH_THRESHOLD` — ボーナスラッシュに入る待ち回転数

## 動作確認

```bash
npm run watch-test                    # watcher が起動後の追記だけ数えることを検証
LLM_DEBUG=1 npm start          # 起動直後に 30,000 トークン投入（3 回転）
LLM_DEBUG=jackpot npm start    # 起動直後に 777 を強制
LLM_DEBUG=audit npm start      # 帯の組み方を 3000 回検証（中央一致とライン外の偽揃い）
```

アプリ上では筐体を**ダブルクリックで 1 回転**、**Shift + ダブルクリックで 777**。

## 構成

```
src/main/index.ts     ウィンドウ生成、777 の膨張・復帰、IPC
src/main/watcher.ts   transcript のポーリングと output トークン集計
src/main/store.ts     累計統計（userData/stats.json）
src/renderer/         筐体・リール（CSS 3D）・演出（canvas）・効果音（WebAudio 合成）
```

外部アセットはゼロ。画像も音声ファイルも使っていない。
